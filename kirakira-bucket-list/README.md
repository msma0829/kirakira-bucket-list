# きらきらバケットリスト

パステルカラーで作った、カテゴリー分け対応のバケットリストアプリです。
入力した内容はブラウザに自動保存されるので、閉じても消えません。

## 1. まずは手元で動かす

ターミナル(コマンドを打つ画面)を開いて、このフォルダの中で以下を実行します。

```
npm install
npm run dev
```

表示されたURL(例: http://localhost:5173)をブラウザで開くと、アプリが確認できます。

## 2. インターネットに公開する(Vercelを使う方法・無料)

一番手軽なのは [Vercel](https://vercel.com) というサービスです。

1. このフォルダをGitHubに登録する
   - GitHubのアカウントを作る(まだなければ https://github.com )
   - このフォルダで以下を実行してGitHubに送る
     ```
     git init
     git add .
     git commit -m "first commit"
     ```
   - GitHub上で新しいリポジトリを作り、案内される通りに `git remote add` → `git push` を実行
2. https://vercel.com にアクセスし、GitHubアカウントでログイン
3. 「New Project」から、先ほど作ったリポジトリを選択
4. 設定はそのままで「Deploy」を押す
5. 数十秒待つと、`https://(プロジェクト名).vercel.app` のようなURLが発行されて、世界中からアクセスできるようになります

## 3. もっと手軽に公開したい場合(Netlify Drop)

GitHubの操作を省きたい場合はこちらが簡単です。

1. ターミナルで `npm run build` を実行 → `dist` というフォルダができます
2. https://app.netlify.com/drop にアクセス
3. `dist` フォルダをそのままブラウザにドラッグ&ドロップ
4. 数秒でURLが発行されます

## 4. スマホのホーム画面に追加したい場合

上記のいずれかで公開したURLを、スマホのSafari/Chromeで開き、
「共有」→「ホーム画面に追加」を選ぶと、アプリのように使えます。
(本格的なアプリストア配信をしたい場合は、また別途ご相談ください)

## 補足

- データは今のところ「そのブラウザだけ」に保存されます(スマホとPCで共有はされません)。複数端末で同じデータを見たい場合は、ログイン機能とデータベース(Supabase等)の追加が必要です。次のステップとして相談できます。
- デザインはTailwind CSS(CDN版)を使っています。本格的な開発に進む際は、ビルドに組み込む形に切り替えるのがおすすめです。
